## Flow Architecture
Network Layer → API Server → Chain Manager → Consensus Engine → Sequential Processing
     ↓              ↓              ↓                ↓                    ↓
P2P Communication  HTTP/RPC     Blockchain      Snowman Protocol    1. Receive Transaction
                   Endpoints    Coordination                        2. Build Vertex
                                                                   3. Run Consensus
                                                                        ↓
                                                              State Manager
                                                                   ↓
                                                    VM State | Block State | Chain State

## Sequential Processing Details
- **Network Layer:** P2P Communication dengan 5 validator nodes
- **API Server:** HTTP/RPC endpoint processing
- **Chain Manager:** Routing ke consensus engine untuk 3 chains (P, X, C)
- **Consensus Engine:** Snowman protocol dengan sequential processing
- **State Manager:** Update VM State, Block State, dan Chain State

## Performance Metrics
- Sequential processing memastikan consistency
- Setiap transaksi diproses secara berurutan melalui semua layer
- Consensus overhead mencakup Snowman protocol processing
- State management meliputi UTXO, balances, dan smart contracts

## Kesimpulan
Sistem monolitik menunjukkan sequential processing yang konsisten sesuai dengan 
arsitektur Avalanche. Semua komponen bekerja dalam urutan yang tepat dari Network 
Layer hingga State Manager.
